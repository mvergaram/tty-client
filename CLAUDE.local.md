# Local Project Language Override

Default language for this project: **English**.

- All UI text (labels, buttons, status messages, dialogs, error messages) must be written in English.
- All code comments and XML doc comments must be written in English.
- Project documentation (`README.md`, `CLAUDE.md`) must be written in English.

This applies to all content that is part of this project's codebase or documentation, regardless of the language used elsewhere. It does not change the language the assistant uses to talk to the user in chat — that is a separate, user-level preference.
